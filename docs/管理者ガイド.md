# 管理者ガイド（情報システム担当者向け）

自治体・公共交通事業者で **GTFS-JP作成アプリ** を導入・運用するための手引きです。
本アプリは「精度」より **「閉域網・オフラインでも安心して長期運用できること」** を最優先に設計しています。

> 現場担当者（時刻表を GTFS-JP に変換する人）向けの操作手順は [利用者ガイド](利用者ガイド.md) を参照してください。

---

## 1. 推奨環境

| 項目 | 推奨 | 備考 |
|---|---|---|
| OS | Windows / macOS / Linux | いずれも可 |
| Python | **3.10 以上**（3.12 で動作確認） | |
| メモリ | 4GB 以上 | 単一路線（30〜70停留所）なら十分 |
| ネットワーク | **不要（オフライン可）** | 既定で外部通信しない。§4参照 |
| Java（任意） | 17 以上 | GTFS Validator（提出前検証）を使う場合のみ |
| GPU（任意） | 不要 | 画像PDFのOCR（MinerU）を使う場合はあると速い |

- **外部サービスへの依存はありません**（フォント・地図タイル・経路探索・使用統計をすべて既定オフライン化）。
- AI 補助機能（読み探索・構造化）は **任意**で、利用者が API キーを入力したときだけ動きます（§4）。

---

## 2. インストール

```bash
# 1) リポジトリを取得
git clone <このリポジトリ>
cd gtfs-jp-creator

# 2) 依存をインストール（どちらか）
pip install -r requirements.txt        # 人が読む一覧（最新版）
pip install -r requirements.lock       # ★動作確認済みの固定版（自治体の長期運用に推奨）
pip install -r app/requirements.txt    # アプリ(Streamlit)側の追加分

# 3) 起動
streamlit run app/app.py
#   → ブラウザで http://localhost:8534 が開く
```

- **`requirements.lock`（バージョン固定）での導入を推奨**します。未固定だと、将来の
  `pip install` が非互換の新版を引いて動かなくなる恐れがあります（5〜10年運用のリスク回避）。
- ポートやアクセス範囲は `.streamlit/config.toml` で設定済みです（§3）。

### 使用ライブラリのライセンス（すべて permissive・商用/再配布可）

| ライブラリ | ライセンス | 用途 |
|---|---|---|
| streamlit | Apache-2.0 | 画面 |
| pandas / numpy | BSD | 表処理 |
| pdfplumber | MIT | PDF のテキスト・座標抽出 |
| openpyxl | MIT | Excel 読み込み |
| pyshp | MIT | 国土数値情報 P11(Shapefile) |
| SudachiPy / SudachiDict | Apache-2.0 | ふりがな生成 |
| folium / streamlit-folium | MIT | 地図 |
| Leaflet（同梱） | BSD-2-Clause | 検証マップHTML（CDN不要） |
| jinja2 | BSD | テンプレート |
| python-docx | MIT | Word 資料の読み取り |
| anthropic（任意） | MIT | AI補助（キー入力時のみ） |

> **コピーレフト（GPL/AGPL）ライブラリは不使用**です。**PyMuPDF(AGPL)・pykakasi(GPL) は
> 除外済み**で、自治体の自己ホスト配布でもライセンス上の制約は生じません。
> 外部データ（国土数値情報 P11・内閣府 祝日 CSV 等）は出典を明記して利用します。

## 3. 起動・公開の設定（`.streamlit/config.toml`）

既定で以下を設定済みです。

```toml
[server]
port = 8534
address = "0.0.0.0"     # 同一LAN内の他端末からも開ける。自分だけなら "localhost"
headless = false        # 起動時にブラウザを自動で開く

[browser]
gatherUsageStats = false  # ★使用統計の外部送信を無効化（テレメトリなし）
```

- **同じ庁内LANの複数端末から使う**：`address="0.0.0.0"` のまま起動し、他端末から
  `http://<このPCのIP>:8534` を開く。
- **1台だけで使う**：`address="localhost"` に変更。
- **HTTPS・独自ドメインで公開**したい場合は [デプロイ手順](デプロイ手順.md) を参照。

## 4. オフライン運用（閉域網対応）

**既定で外部通信は発生しません。** 必要な場合だけ、環境変数で外部リソースを有効化します。

| 環境変数 | 既定 | 役割 |
|---|---|---|
| `GTFS_TILE_URL` | （なし＝背景地図なし） | 地図の背景タイルURL。閉域網では**自前タイルサーバ**のURLを指定。例: `https://tile.openstreetmap.org/{z}/{x}/{y}.png`（利用規約は各自確認） |
| `GTFS_DICT_DIR` | `skills/gtfs-jp-creator/references/dictionaries/` | 読み辞書と監査ログの保存先。**庁内共有ドライブ**等へ移設可 |
| `GTFS_AUDIT_LOG` | `<GTFS_DICT_DIR>/audit_log.jsonl` | 監査ログの保存先を個別指定したい場合 |
| `ANTHROPIC_API_KEY` | （なし＝AI機能OFF） | AI補助を使う場合のみ。**未設定なら外部送信なし** |

- **座標確認の地図**：既定はタイルなし（灰色背景＋ピン）で、オフラインでも座標確認できます。
  背景地図が必要なら `GTFS_TILE_URL` を設定してください。
- **経路(shapes.txt)**：既定はオフライン（停留所を直線で結ぶ）。道なり経路が必要な場合のみ、
  パイプライン設定で OSRM を有効化します（`use_osrm=true`＋任意で自前 `osrm_url`）。
- **フォント・使用統計**：外部フォント（Google Fonts）は使わず OS 同梱フォント。使用統計の送信も無効。

> **AI補助を全庁で使わせない**運用にする場合：`ANTHROPIC_API_KEY` を配布・設定しないだけで、
> AI 機能は動きません（読み生成は SudachiPy＋辞書＋規則のみで完結）。

## 5. バックアップ・復元

利用者の作業は「共有コード（8桁）」ごとに自動保存されます。**次の3か所を定期バックアップ**してください。

| 対象 | 既定の場所 | 内容 |
|---|---|---|
| 作業の自動保存 | `~/.gtfs_jp_app/`（各ユーザのホーム直下） | 各案件の `session_<コード>.json` と生成物 `out_<コード>/` |
| 読み辞書 | `GTFS_DICT_DIR`（既定は同梱の dictionaries/） | 全国/自治体/路線/利用者の各辞書 CSV |
| 監査ログ | `GTFS_AUDIT_LOG`（既定は `<dict>/audit_log.jsonl`） | 誰が・いつ・どの読みを変更したか（追記専用） |

- **復元**：アプリ起動画面で **共有コード（8桁）を入力**すると、そのプロジェクトの作業を引き継げます。
  自動保存フォルダ（`~/.gtfs_jp_app/`）が残っていれば、再起動後も④⑤⑥・ダウンロード・再生成を復元できます。
- **共有ドライブ運用**：`GTFS_DICT_DIR` を庁内共有フォルダに向けると、辞書と監査ログを部署間で共有できます。
- 監査ログは **追記専用（改ざん防止）** です。バックアップ時は上書きせず追記履歴を保全してください。

## 6. トラブルシューティング

| 症状 | 原因・対処 |
|---|---|
| ポート 8534 が使用中で起動しない | 別プロセスが使用中。`.streamlit/config.toml` の `port` を別番号に変更 |
| 他端末からアクセスできない | `address="0.0.0.0"` になっているか、庁内 FW でポートが通っているか確認 |
| 地図に背景が出ない | 仕様（既定オフライン）。背景が必要なら `GTFS_TILE_URL` を設定（§4） |
| 画像PDF（スキャン）で停留所が0件 | 文字情報がないPDF。テキスト選択できるPDF/Excelを使うか、`pip install -U "mineru[core]"` で OCR を導入 |
| 提出前検証（Validator）が動かない | Java 17+ が必要（任意機能）。未導入でも GTFS-JP 拡張の独自検証（Java不要）は動きます |
| AI補助が使えない | 仕様（既定OFF）。使う場合のみ `ANTHROPIC_API_KEY` を設定 |
| ふりがなが一部違う | 地名は自動で完全化できません。④で人が確認・修正（[利用者ガイド](利用者ガイド.md) §ふりがな） |
| 自動保存の失敗を確認したい | ログ名 `gtfs.collab` に保存/復元の失敗が記録されます（コンソール/ログ） |

- 障害切り分け用に、保存・復元の失敗は `gtfs.collab` ロガーに記録されます（処理は続行）。

---

## 7. セキュリティ・データ取り扱い

- **既定で外部送信なし**（フォント・地図・使用統計・AI すべてオフライン/OFF）。
- AI補助を使う場合のみ、停留所名が Claude API（外部）へ送られます。庁内のデータガバナンス方針に
  従い、必要に応じて AI 機能を無効（キー未配布）にしてください。
- API キーは画面のパスワード欄で入力し、ディスクには保存しません（セッション内のみ）。
- アップロードした時刻表ファイルは作業フォルダ内でのみ処理されます。
